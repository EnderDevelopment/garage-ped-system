# Garage Ped System

Interactive garage system with peds for storing and retrieving vehicles.

## Features

- Interactive garage peds
- Store and retrieve vehicles

## Requirements

- FiveM server
- ESX framework
- MySQL database

## Installation

1. Download the script
2. Place the script in your FiveM server's resources folder
3. Add `start garage-ped-system` to your server.cfg
4. Import the database.sql file into your MySQL database

## Usage

1. Players can interact with the garage peds to store and retrieve their vehicles
2. The peds will be spawned at the configured locations

## Configuration

- Configure the garages in the config.lua file
- Set the ped models, coordinates, and blip settings
